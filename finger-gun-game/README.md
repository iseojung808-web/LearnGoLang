# 🔫 핑거건 좀비 사냥 (Finger-Gun Zombie Hunt)

키보드·마우스로 하는 좀비 슈팅 브라우저 게임입니다. 무기는 6종이고, 웹캠으로 손가락 총을 인식하는 카메라 모드도 있어요.
손 인식은 [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker)를 브라우저에서 바로 돌립니다 (영상은 서버로 전송되지 않아요).

## 실행

```bash
cd finger-gun-game
go run .
# → http://localhost:8080 접속
```

브라우저는 `https` 또는 `localhost`에서만 카메라를 허용하기 때문에 작은 Go 서버로 띄웁니다.
(정적 파일 하나라서 `python3 -m http.server` 같은 다른 서버로 띄워도 됩니다.)

## 조작법 (키보드 + 마우스, 기본)

| 동작 | 키 |
|---|---|
| 조준 | 마우스, 또는 `←↑↓→` (Shift = 정밀 조준) |
| 발사 | 좌클릭 또는 `F` (누르고 있으면 연사, 기관단총/물총) |
| 이동 | `W` / `S` 앞뒤, `A` / `D` 좌우 (뒤로는 좀비보다 느려요) |
| 재장전 | `R` (탄창이 비면 자동) |
| 무기 교체 | `1`~`6`, `Q`/`E`, 마우스 휠 |
| 수류탄 | `G` 또는 우클릭 |
| 방패 | `Space` 누르는 동안 |
| 일시정지 | `P` / `Esc` |
| 시작 / 재시작 | `Enter` |

### 무기

| # | 무기 | 특징 |
|---|---|---|
| 1 | 🔫 권총 | 데미지 3, 15발, 탄약 무한. 좀비 한 방 |
| 2 | 💥 샷건 | 10발 산탄 × 2, 넉백. 가까운 적 증발 |
| 3 | ⚡ 기관단총 | 데미지 2 연사, 40발. 쏠수록 탄이 퍼짐 |
| 4 | 🎯 저격총 | 데미지 30, 일렬로 관통 |
| 5 | 🚀 로켓 | 데미지 16 범위 폭발, 2연발 |
| 6 | 💦 물총 | 데미지 0, 대신 좀비가 느려지고 **젖은 좀비는 1.5배 데미지** |

💀 **헤드샷**: 적의 머리 쪽(위쪽)을 맞히면 데미지 2배.

화면 오른쪽 아래에 1인칭 총이 보여요. 쏠 때 반동, 총구 화염, 탄피, 궤적이 나오고, 재장전 때는 탄창이 빠졌다 끼워져요(샷건은 펌프질, 로켓은 새 로켓 장전).

📦 상자를 쏘거나 걸어가서 밟으면 탄약, 수류탄, 치킨(체력) 중 하나가 나와요. 30초마다 웨이브가 오르면서 보스 🧌가 등장합니다.

적: 🧟 좀비, 👻 유령(빠르고 흔들림), 👹 오우거(맷집), 🧌 보스, 🛸 UFO(보너스 1000점), 🐱 고양이(**쏘지 마세요**, -500점).

## 카메라 모드 (손가락 총, 실험실)

메뉴에서 "📷 카메라 모드"를 누르면 웹캠 손 인식으로도 플레이할 수 있어요. 무기 교체와 수류탄은 키보드로 하면 됩니다.

| 동작 | 손 모양 |
|---|---|
| 조준 | 👉 검지(+중지) 펴고 엄지 세운 총 모양. 손끝이 조준점 |
| 발사 | 💥 총 모양으로 손목을 위로 **휙** 튕기기 (연사 무기는 짧게 연사) |
| 재장전 | ✋ 손바닥 쫙 펴고 잠깐 유지 |
| 방패 | ✊ 주먹 쥐기 |
| 이동 | ↔️ 조준점을 화면 양 끝으로 |
| 재시작 | ✋ 게임오버 화면에서 손바닥 1초 |

발사 감도는 `[` / `]`. 카메라가 안 켜지거나 까맣게 나오면 `check.html`(카메라 진단)을 열어보세요.

## 발사 인식 방식

실제 손목 튕기기는 너무 빨라서 웹캠에 모션 블러가 생기고, 트래커가 그 순간 손을 놓치는 경우가 많습니다.
그래서 세 가지 중 하나라도 걸리면 발사합니다:

1. **상승** — 손끝이 손 크기 대비 빠르게 위로 튐
2. **스냅** — 손가락 방향이 짧은 시간에 크게 회전
3. **블러** — 안정적으로 보이던 총 모양이 갑자기 사라짐 (너무 빨라서 못 잡은 경우)

발사 순간의 조준점은 튕기기 직전 위치(약 140ms 전)를 써서, 반동 때문에 총알이 위로 새지 않게 했습니다.

## 카메라 모드 팁

- 손을 카메라 정면으로 찌르기보다 **옆으로 비스듬히** 겨누면 인식이 훨씬 잘 됩니다.
- 조명이 밝을수록 모션 블러가 줄어 발사 인식이 좋아집니다.
- 발사가 너무 잘/안 되면 `[` `]`로 감도를 조절하세요.
